# 离线复算

解压后在包根目录执行。需要 Linux、g++（C++17）。仅使用包内源码与 CSV，不启动 ROS 或连接硬件。

```bash
bash offline_tools/run_filter.sh
```

结果写到新目录 `reproduction_output/`，原始证据不变。预期：输出绝对峰值约 8.596901，增益绝对峰值约 2070.815942，首次负 P00 位于第 14739 次调用。

进一步试算需要 Python 3、numpy、PyYAML、matplotlib、Pinocchio（原环境版本 4.1.0）。使用装有这些依赖的 Python 执行：

```bash
python3 offline_tools/audit_portable.py
```

原工作机的 Pinocchio 位于 `/opt/openrobots/lib/python3.12/site-packages`，对应环境示例：

```bash
PYTHONPATH=/opt/openrobots/lib/python3.12/site-packages LD_LIBRARY_PATH=/opt/openrobots/lib python3 offline_tools/audit_portable.py
```

`audit_portable.py` 仅调整原 `audit.py` 的输入、源码和结果目录，数值计算保持原样。使用包内安装 URDF 与配置，输出到 `reproduction_output/`。原实验与结果仍保存在事故目录。

开环试算采用理想 15 Hz 目标、65.2 秒静止预热和无物理反馈条件；用于排查计算链路，不能替代事故物理闭环复现。包内不含完整机器人工程、完整数据集或事故现场录像。
