# 左臂零位标定规格

## 目标

为此前未使用过的左臂提供一套可重复执行的零位标定流程。操作者需要先让左臂保持不被程序移动，确认反馈正常后手动摆到期望初始姿态，并把该姿态的七个关节反馈值写入项目源码中的零位配置。

## 必须行为

1. 提供专用的 Make 命令启动左臂标定模式；普通 `make servo` 的原有行为不变。
2. 左臂标定模式启动后不得执行自动回零、默认零位保持、轨迹插补或接受上位机控制指令；左臂七个关节须以电流模式下发零电流。
3. 标定模式启动时，右臂不得回到配置零位，而是以启动时读到的七个反馈位置、原有低刚度 PD 参数保持当前位置。
4. 标定模式仍须连续发布 `/dexbotCtl/dualArmCtl_fdback`，以便操作者监看并由保存工具采样。
5. 提供独立的保存命令；它只能在接收到完整、连续、有限且稳定的七关节反馈窗口后写入零位。没有有效反馈、反馈全为零或手臂仍在移动时，必须失败且不能改配置。
6. 保存的目标必须是 `ros2_ws/src/ctl_msgs_hw/config/zeropos.yaml` 的 `left_arm` 七个已有关节键；写入前备份原文件，写入采用同目录临时文件和原子替换。配置写入后，运行中的伺服节点不得重新加载或运动；操作者须停止它、重新构建、再普通启动验证。
7. 新建中文标定文档，给出上电、急停、EtherCAT、左臂电机绿灯、专用命令、监看、手动摆臂、保存、备份恢复、重新构建和验证的具体顺序；明确左臂在零电流时可能因重力下垂，必须托住机械臂且不允许启动其他控制节点。

## 约束

- 不在无真实硬件和现场人员的情况下启动 EtherCAT 伺服测试。
- 不新增第三方 Python 或 C++ 依赖；保存工具延迟导入 ROS Python 模块，使纯配置逻辑可由 pytest 测试。
- Make 命令接受 `SIDE=left|right`，但本次文档只指导左臂；节点只允许 `left` 标定参数，其他值必须拒绝启动。
- 完全保留工作区中用户已有的未提交修改。

## 验收标准

- `make calibrate-arm-zero SIDE=left` 传递 ROS 参数并启动安全校准模式；无 `SIDE` 或非法值不启动任何节点。
- `make save-arm-zero SIDE=left` 只会在稳定且非零的左臂反馈窗口后更新源码配置，并创建时间戳备份。
- 普通 `make servo` 不携带该参数且仍使用原来的自动回零流程。
- `make test` 通过，且不需连接机器人。
